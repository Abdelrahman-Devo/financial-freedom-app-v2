# الحرية المالية — النسخة المدمجة

هذه النسخة مبنية على التطبيق الأساسي الكامل، مع تحسينات الواجهة الجديدة مع الحفاظ على أقسامه وطريقة الميزانية القديمة.

## تقسيم الدخل الافتراضي
- الأساسيات: 55%
- الرفاهية: 5%
- الديون: 10%
- الادخار: 15%
- الاستثمار: 10%
- الصدقات: 5%

عند إضافة دخل إلى إحدى المحافظ، يحفظ التطبيق توزيع المبلغ على الأقسام الستة تلقائيًا، وتنعكس المبالغ على ميزانية الشهر. يمكن تعديل النسب بشرط أن يكون مجموعها 100%.

## الحفاظ على البيانات
- يستخدم التطبيق مفتاح التخزين الأصلي `financialFreedom.v1` للحفاظ على بيانات النسخة القديمة.
- إذا وجد بيانات النسخة الحديثة تحت `financialFreedom.fresh.v1` ولم يجد بيانات النسخة القديمة، يحاول نقل المحافظ والعمليات والأهداف والديون والالتزامات والأصول وصندوق الطوارئ تلقائيًا.
- لا يحذف مفتاح بيانات النسخة الحديثة أثناء النقل. يُنصح دائمًا بتصدير نسخة احتياطية قبل تحديث التطبيق.

## الواجهة
- الوضع الفاتح والداكن مع حفظ الاختيار.
- قوائم اختيار مخصصة متوافقة مع ألوان وهوية التطبيق بدل قوائم النظام الافتراضية.
- مراعاة المساحة الآمنة أعلى الشاشة وأسفلها على Android.

## إعداد Android عبر Capacitor
يتطلب Node.js وAndroid SDK لبناء APK.

```bash
npm install
npx cap add android
npx cap sync android
```

إذا كان مجلد `android` موجودًا بالفعل فلا تنفذ `cap add android` مرة أخرى؛ استخدم `npx cap sync android`.

## المزايا الأساسية
- الميزانية الشهرية وتقسيم الدخل والفئات الست.
- المصروفات والدخل والتقارير اليومية والأسبوعية والشهرية.
- المحافظ والأرصدة والتحويلات بين المحافظ.
- أهداف الادخار وسجل المساهمات.
- إدارة الديون وسجل السداد والتحصيل.
- الالتزامات الشهرية وتصنيفها حسب طبيعتها.
- التقويم المالي والأصول والاستثمارات وصافي الثروة.
- صندوق الطوارئ والتوقعات والتنبيهات المالية وتحديات الادخار.
- النسخ الاحتياطي والاستعادة وتصدير CSV وإخفاء الأرصدة.

## حدود الاختبار
تم فحص صياغة JavaScript وبنية أرشيف المشروع آليًا. يلزم اختبار APK على جهاز Android فعلي قبل اعتماد النسخة نهائيًا، خصوصًا التثبيت، التخزين المحلي، القوائم، وشريط الحالة.
