# الحرية المالية — مشروع جديد من الصفر

تطبيق عربي RTL يعمل محليًا في المتصفح ويمكن تهيئته كتطبيق Android باستخدام Capacitor.

## التشغيل السريع
- افتح `index.html` مباشرة للتجربة الأساسية.
- البيانات تحفظ محليًا في LocalStorage تحت المفتاح `financialFreedom.fresh.v1`.
- استخدم صفحة التقارير لتنزيل نسخة JSON أو CSV.

## إعداد Android عبر Capacitor
يتطلب Node.js وAndroid Studio واتصال إنترنت لتثبيت الحزم.

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

إذا كان مجلد `android` موجودًا بالفعل فلا تنفذ `cap add android` مرة أخرى؛ استخدم `npx cap sync android`.

## المزايا الموجودة في هذا الإصدار
- لوحة رئيسية وملخص شهري وتوقع مبسط لنهاية الشهر.
- تسجيل دخل ومصروفات وتصنيفات ومحفظة لكل عملية.
- محافظ متعددة وأرصدة افتتاحية وتحويلات بينها.
- ميزانية شهرية وأهداف ادخار وديون وسداد مسجل كمصروف.
- التزامات وتقويم مواعيد.
- أصول واستثمارات يدوية وحساب صافي الثروة.
- صندوق طوارئ يدوي.
- تقارير مبسطة وتصدير CSV ونسخ احتياطي/استعادة JSON.
- إخفاء الأرصدة، اختيار العملة، واجهة PWA قابلة للتخزين المؤقت.

## حدود يجب معرفتها
- البيانات محلية على الجهاز؛ لا توجد مزامنة سحابية أو حسابات مستخدمين.
- لا يوجد قفل بيومتري حقيقي أو إشعارات Android مجدولة بعد.
- أسعار الأصول والاستثمارات تدخل يدويًا ولا توجد تغذية أسعار مباشرة.
- هذه نسخة تأسيسية عملية وليست إصدارًا إنتاجيًا مُعتمدًا قبل اختبارات الاستخدام والأمان على أجهزة فعلية.
